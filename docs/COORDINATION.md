Report latency percentiles, throughput, error rates, resource use and database/query behavior where measurable. Optimize demonstrated bottlenecks, then rerun the affected checks. Independent visual audit complements but does not replace engineering review. Preserve accurate demo/live distinctions.

Existing hosted authentication/database blockers remain explicit BLOCKED gates: do not call affected functionality production-ready or silently skip them. Continue fixes and available validation; report missing prerequisites to user when they prevent completion.
