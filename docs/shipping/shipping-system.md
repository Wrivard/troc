# Shipping system

Status: local/demo simulation implemented; carrier integration and operational fulfillment policies are **Planned**.

Existing commerce calculates aggregate Canadian shipping using configured card/weight/thickness tiers, seller thresholds and level eligibility. Smart Cart includes shipping in delivered basket cost. These values are simulation assumptions, not live carrier quotes. Do not change shipping economics while adding seller inventory. Lettermail, tracking, packaging and lost-mail policy documentation must reflect approved operational rules before launch.
