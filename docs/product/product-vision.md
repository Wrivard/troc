# Product vision and marketplace strategy

Status: **Planned** strategy; individual feature availability is recorded in the roadmap and implementation status.

TROC is Canadian-first and CAD-first. Sellers should manage inventory once and add TROC as another sales channel. Collectors should find cards across Canadian sellers and minimize total delivered basket cost, including shipping.

The cold-start priority is inventory liquidity and transaction quality. A smaller set of established sellers with substantial inventory is more useful than empty signup counts. Separate seller and collector prelaunch lists should build supply and demand before broad launch. Founding-seller/referral rewards require meaningful qualified contribution.

The intended flywheel is inventory import → useful Canadian supply → wishlist and Smart Cart matching → legitimate transactions → privacy-safe demand and transaction data → better seller decisions → seller referrals → more supply. Collections connect ownership to future selling and missing cards to buying. Each stage must use real activity; inventory, demand, prices, savings, reputation and transactions must never be fabricated.
