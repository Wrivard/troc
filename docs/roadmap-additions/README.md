# TROC — Added .5 Milestones

Milestones 1–3 are already complete. Do not restart or rewrite them.

These additions extend the existing roadmap to address marketplace cold-start, seller inventory friction, pre-launch audience building, buyer network effects, integrations, and TROC's long-term moat.

## Added milestones
- 3.5 — Frictionless Seller Inventory & Integration-Ready Architecture
- 4.5 — TROC Seller API & Live-Sync Foundation
- 5.5 — Founding Seller & Seller Referral System
- 6.5 — Pre-Launch Buyer/Seller Growth System
- 7.5 — Wishlist & Demand Network
- 8.5 — TROC Smart Cart
- 9.5 — Canadian Market Data
- 10.5 — Collection → Marketplace Flywheel

## Core strategy
**Seller:** TROC should be an additional sales channel, not another inventory system sellers must maintain manually.

**Buyer:** TROC should become the easiest way in Canada to find and buy a multi-card order at the best delivered cost.

**Pre-launch:** build buyer and seller lists before public launch, then seed sufficient inventory before sending large amounts of buyer traffic.

**Long term:** build defensibility through integrations, inventory, wishlists, Canadian transaction data, demand data, reputation, referrals, and cart optimization.

## Rule for every .5 milestone
1. Review existing implementation first.
2. Preserve working functionality.
3. Implement only the current milestone.
4. Add/update tests.
5. Review security and performance.
6. Update documentation.
7. Audit, review, fix, and optimize.
8. Confirm production build/deployment is healthy before continuing.

Never claim integrations, partnerships, market prices, savings, demand, sales, or marketplace data that do not actually exist.
