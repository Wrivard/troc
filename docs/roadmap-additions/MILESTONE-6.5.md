# Milestone 6.5 — Pre-Launch Buyer & Seller Growth System

## Purpose
Build demand and supply before broad public launch. This may be safely deployed earlier than its roadmap number if separated from unfinished marketplace functionality.

## Requirements
### Pre-launch landing
Two clear paths: **Collector Early Access** and **Founding Seller**. Do not send visitors into unfinished marketplace flows.

### Collector waitlist
Keep short. Capture useful data such as email, games, buying frequency, current channels, major frustrations, province/region where useful and optional wishlist. Track acquisition/referral source.

### Seller waitlist/application
Capture contact, selling channels, inventory software, games, approximate inventory, province and seller/store type. Include channels like eBay, Shopify, TCGplayer, Facebook/LGS; tools like SortSwift, CardUploader, BinderPOS, spreadsheet/custom.

### Seller lead admin
Filter/prioritize leads by inventory size, game, experience, integration compatibility, province and application status. This is prioritization, not automatic rejection.

### Pre-launch referrals
Track referral attribution before launch. Seller referrals must connect to Milestone 5.5 upon activation. Buyer referrals can support early-access priority; do not promise financial rewards unless configured.

### Funnel analytics
Track landing visit → CTA → form start → completion → referral → invitation → account activation → seller activation → first inventory → first transaction.

### Launch cohorts
Support internal, founding sellers, private alpha, collector closed beta and public cohorts rather than one simple launch boolean.

### Documentation
Document pre-launch strategy, both waitlists, source tracking, cohorts and launch-readiness metrics.

## Audit
Review privacy/consent, attribution, form abandonment, spam/duplicates, admin security, analytics accuracy and mobile UX.
