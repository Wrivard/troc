# TROC — Post Style-Guide Build Pack

The TROC `/style-guide` milestone is already complete and approved.

This pack defines the rest of the MVP and the implementation sequence for the existing Replit project.

## Critical instruction
**Do not redesign or replace the approved style guide.**
The existing design tokens, components, logo usage, typography, spacing, themes, navigation primitives and visual language are now the source of truth.

When building new pages:
- reuse the approved components;
- extend them only when genuinely required;
- add any new reusable visual primitive back to `/style-guide`;
- never silently create a second design system.

## Product
TROC is a bilingual, Canada-first marketplace for trading cards.

Launch games:
- Pokémon
- Magic: The Gathering
- Yu-Gi-Oh!
- One Piece
- Riftbound

Launch geography:
- Canadian buyers
- Canadian sellers
- CAD only
- English + French

Launch seller types:
- Individual Seller
- Professional Seller
- Verified Online Seller
- Verified Hobby Shop

## Core commercial principle
TROC must make low-value singles viable.

The product must optimize:
- cards per order;
- seller-order subtotal;
- shipping per card;
- seller consolidation;
- one buyer checkout across multiple sellers;
- combined shipping;
- seller minimums;
- promotions;
- collection/want-list matching;
- Smart Cart optimization.

## MVP
The MVP is fully functional except real money movement and real payout/KYC integrations.

Use simulated:
- card payment;
- processing fee;
- payout;
- refund;
- marketplace credit funding.

Build the data model as if these will become real later.

## Demo vs real data
Demo sellers/orders/reviews/GMV/activity may be seeded to demonstrate the product.

They MUST be:
- tagged as demo;
- removable safely;
- separate from real leads.

Real data from day one:
- buyer waitlist;
- founding seller applications;
- LGS partner leads;
- partner/investor leads.

Read all files in this pack before coding.
