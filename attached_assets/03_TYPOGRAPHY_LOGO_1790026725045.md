# 03 — Typography & Logo System

## Typography
Use a clean, modern, highly readable sans-serif that can legally ship with the app. Do not bundle or expose proprietary font files.

Desired feel: similar discipline to Geist / Inter / modern grotesk typography.

Hierarchy should include:
- display/hero
- H1–H6
- body large / regular / small
- label
- metadata
- price numerals
- table text

Prices and key marketplace metrics should be especially legible.

## Wordmark usage
Create a reusable `TrocLogo` component with variants:
- dark background
- light background
- monochrome
- compact
- wordmark only
- wordmark + provisional custom leaf

Respect clear space and minimum sizes. Never stretch/skew the raster asset.

## Icon/favicons
Use a provisional T-based app icon / custom-leaf icon only as a placeholder. The final custom icon comes later.
