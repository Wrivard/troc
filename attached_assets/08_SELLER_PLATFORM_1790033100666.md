# Seller Platform

## Application
`/seller/apply`

Types:
- Individual Seller;
- Professional Seller;
- Verified Online Seller;
- Verified Hobby Shop.

Collect contact, province, existing channels/URLs, inventory size, games, sales range, platforms, tax fields and KYC/payout placeholders.

Manual admin approval in MVP.

## Dashboard
Sales/revenue demo metrics, orders, cards sold, AOV, cards/order, listings, inventory value, views, conversion, reputation, level progress, plan, promotions.

## Inventory
Catalog search, listing management, price, quantity, condition, status, SKU, storage/bin location, bulk actions and export.

## Listing flow
Catalog product → printing/variant → language → condition → quantity → price → SKU/location → photos if required → offers toggle → publish.

## CSV import
Upload → map columns → parse → preview → validate → row errors → catalog match → duplicate strategy → batched commit → report.
Design for tens of thousands of rows.

## Levels
New → Established → Trusted → Elite.
Earned only.

## Plans
Free → Pro → Business.
Plan controls tools/customization, not trust.

## Founding sellers
First 250 approved: Founding Seller + Pro free forever.

## Promotions
Quantity/spend discounts, coupons, sales, eligible free-shipping thresholds and promoted listing percentage.

## Team
Owner, Manager, Inventory, Fulfillment, Customer Service.

## Analytics
Revenue, orders, AOV, cards/order, sell-through, inventory age, conversion, promotion performance, demand.
