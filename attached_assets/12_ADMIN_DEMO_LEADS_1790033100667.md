# Admin, Demo Data & Real Leads

## Admin
Protected server-side and audited.

Manage:
- seller applications;
- sellers;
- users;
- listings;
- orders;
- issues;
- reviews;
- catalog corrections;
- promotions;
- reference prices;
- demo status;
- real leads.

## Seller admin
Approve/reject/suspend, verify, assign badges/level/plan/Founding Seller, inspect activity, freeze simulated payout and write internal notes.

## Catalog admin
Manage games, sets, products, printings, variants, aliases, mappings, prices and correction queue.

## Demo data
Seed repeatable demo batches for buyers, sellers, listings, orders, reviews, notifications, price history, collections, want lists and activity.

Tag demo provenance.

## Purge
Protected purge removes demo marketplace data while preserving canonical catalog/provider mappings and all real leads.

## Real leads
Founding Seller, Buyer Early Access, LGS Partnership, Partner/Investor.

Do not mix fake traction with these real records.
