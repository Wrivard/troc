# Collector Platform

## Collection
`/collection`
Game → Set → visual binder/checklist.

Owned/missing, variant, language, condition, quantity and estimated reference value.

## Master sets
Default TROC checklist plus customizable inclusion rules.
Show progress, missing cards, estimated missing cost.
CTA: Find My Missing Cards → Smart Cart.

## Wishlist
Lightweight wishlist.

## Want lists
Named lists with quantity, language, minimum condition, variant constraints and target price.
Shareable URL.
CTA: Buy with Smart Cart.

## Saved searches
Persist query/filter criteria.

## Price alerts
Notify when matching listing appears at/below target.

## Seller following
Follow sellers; automatic notifications for meaningful restock or promotion.

## Demand
May show aggregate want demand without exposing user identities.
