# 07 — Copy & Localization

TROC launches bilingual: English and French.

Do not hard-code user-facing English text inside reusable components. Set up localization keys now, even if style-guide examples cover only a representative set.

Tone:
- concise
- confident
- human
- practical
- not hype-heavy
- no long SaaS marketing paragraphs

Examples:
EN: Built here. For collectors here.
FR: Use natural Quebec/Canadian French rather than literal machine translation.

EN: More cards. Less shipping.
FR: concise equivalent chosen for naturalness.

Labels must remain usable when French text is longer.
