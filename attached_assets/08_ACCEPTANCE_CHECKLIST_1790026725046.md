# 08 — Style Guide Acceptance Checklist

Do not proceed to marketplace development until all are true:

- [ ] `/style-guide` exists and is polished.
- [ ] Default Canada Dark theme matches approved black/red/white/grey direction.
- [ ] Canada Light theme works.
- [ ] Selected TROC wordmark direction is respected.
- [ ] Leaf is treated as provisional/custom, not copied from official flag.
- [ ] Tokens are semantic and centralized.
- [ ] Components are reusable, not page-local one-offs.
- [ ] Core marketplace-specific components exist.
- [ ] Hover/focus/loading/error/disabled states exist.
- [ ] Mobile previews are convincing.
- [ ] EN/FR architecture is present.
- [ ] Accessibility basics pass.
- [ ] No full marketplace/business logic has been prematurely built.
- [ ] No proprietary font file is embedded.
- [ ] No unapproved extra brand colors have been introduced.
