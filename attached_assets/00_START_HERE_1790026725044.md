# START HERE — TROC Style Guide Milestone

## Objective
Create a production-quality TROC design system and a `/style-guide` route that becomes the visual source of truth for the marketplace.

This milestone should establish:
1. global design tokens;
2. typography hierarchy;
3. logo/brand usage components;
4. navigation and shell primitives;
5. marketplace-specific UI components;
6. forms, feedback and states;
7. dark + light theme foundations;
8. responsive behavior;
9. English/French-ready copy architecture;
10. accessibility standards.

## Do not build yet
No catalog database, no seller dashboard, no Smart Cart, no payments, no order logic, no full marketplace pages. A few realistic static/demo component examples are fine only to demonstrate the design system.
