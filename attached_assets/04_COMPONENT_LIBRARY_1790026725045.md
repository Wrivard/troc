# 04 — Component Library

The `/style-guide` route must render real reusable components and all major states.

## Core UI
- Button: primary, secondary, tertiary, destructive, icon
- Input, textarea, select, combobox/search
- Checkbox, radio, switch
- Tabs
- Chips/filter chips
- Tooltip
- Popover
- Dropdown/menu
- Modal/dialog
- Drawer/sheet
- Toast
- Alert/banner
- Badge/status
- Pagination
- Breadcrumbs
- Skeleton/loading
- Empty state
- Error state

## Marketplace-specific primitives
- Global search bar
- Game chip
- Product/card tile
- Compact product row
- Price block
- Reference-price label
- Condition badge: NM, LP, MP, HP, DMG
- Variant badge
- Seller badge: Verified, Top Seller, Hobby Shop, Founding Seller
- Seller row/offer row
- Seller storefront header
- Promotion badge
- Sale price treatment
- Quantity selector
- Seller-minimum progress
- Free-shipping progress
- Cart seller group
- Smart Cart savings callout
- Recently-sold ticker item
- Collection progress card
- Notification item
- Data table
- Metric/stat card

## States
Every interactive component should demonstrate:
- default
- hover
- focus-visible
- active
- disabled
- loading
- validation error where relevant
