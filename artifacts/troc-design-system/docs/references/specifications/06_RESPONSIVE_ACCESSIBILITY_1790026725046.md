# 06 — Responsive & Accessibility Requirements

Mobile is critical. Components must be designed for touch and narrow screens first, then expand to desktop.

Breakpoints should be tokenized/consistent.

Requirements:
- keyboard-navigable controls;
- visible focus indicators;
- semantic labels and landmarks;
- accessible dialogs/drawers;
- no information conveyed only through color;
- WCAG-conscious contrast;
- usable touch targets;
- screen-reader labels for icon buttons;
- reduced-motion support;
- responsive tables that become cards/scroll appropriately rather than breaking;
- search/filter behavior designed for mobile.
