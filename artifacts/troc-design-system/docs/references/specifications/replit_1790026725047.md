# TROC — Replit Style Guide Context

Build only the TROC design system and `/style-guide` milestone first. Do not build the marketplace yet.

TROC is a Canada-first trading-card marketplace. The visual system is LOCKED to a minimalist, premium, modern tech-marketplace direction using red, black/charcoal, white/off-white and grey. The selected TROC wordmark reference is italic/forward-moving. The maple leaf beside it is a concept reference only: the production mark must use a custom TROC leaf, not a traced official Canadian 11-point leaf.

Read `00_START_HERE.md`, then all numbered files. Use the three images in `/assets` as visual reference. Recreate the visual language with reusable React components and CSS/design tokens rather than embedding the board as an image.

Non-negotiables:
- React + TypeScript.
- Responsive mobile-first implementation.
- EN/FR localization-ready strings.
- Dark/default Canada theme first; light theme supported.
- Accessibility and keyboard/focus states.
- No rainbow TCG styling, cartoon UI, generic SaaS illustrations, excessive gradients or glassmorphism.
- Product/card artwork should provide most secondary color.
- Do not invent a new logo.
- Do not move on to marketplace features until the style guide is reviewed and approved.
