# 05 — `/style-guide` Page Specification

Create a polished internal brand/design-system page. It should feel like a real design-system site rather than an unstyled list.

Sections:
1. Brand overview
2. Logo / lockups / clear-space examples
3. Color tokens
4. Dark and light theme comparison
5. Typography hierarchy
6. Spacing/grid/radius/shadow
7. Buttons
8. Form controls
9. Navigation/header/search
10. Marketplace product components
11. Seller/reputation components
12. Cart/Smart Cart components
13. Collection components
14. Data tables/dashboard primitives
15. Feedback/loading/error/empty states
16. Notifications/modals/drawers
17. Mobile component preview
18. Accessibility notes

Include a small mock marketplace hero/component composition using the approved branding, but do not build the full homepage yet.
